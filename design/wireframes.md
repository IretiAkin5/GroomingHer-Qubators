# Screen inventory and preview structure

The [design plan](../GroomingHer_Design_Plan.md) defines the ordered layouts. The public site uses an editorial hero, original learning illustration, three equal role cards, learning topics, school-to-home steps, a labelled Christian reflection, privacy, print access, sample resources, planned school pilot, FAQs and footer.

Public routes: `/`, `/about`, `/solutions/girls`, `/solutions/parents`, `/solutions/schools`, `/how-it-works`, `/resources`, `/contact`, `/get-started`, `/login`; policies/support are available without accounts.

Role onboarding: `/onboarding/girl`, `/onboarding/parent`, `/onboarding/school`. Demonstration spaces use `/demo/girl`, `/demo/parent`, `/demo/school`. Each identifies the role and contains its own navigation, temporary fictional content and visible exit. See [build stages](../docs/BUILD_STAGES.md) for implemented journeys and evidence.

Functional screens use complete labels/instructions. Any future marketing-copy gaps belong to the landing page only. The supplied PRD 3.1 landing copy is used for the first preview.
